# Sistema Manicure Nails Quijo

## Descrição do Projeto

Este projeto consiste em um sistema computadorizado desenvolvido para automatizar e reorganizar a gestão de atendimento de manicures, substituindo a agenda manual. O sistema permite o controle prático da agenda, o armazenamento de informações das clientes e o gerenciamento do estoque de produtos.

## Tecnologias Utilizadas

* Java
* MySQL
* Git e GitHub
